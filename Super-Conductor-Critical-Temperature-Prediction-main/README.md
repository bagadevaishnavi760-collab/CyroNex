# Super-Conductor-Critical-Temperature-Prediction
# Overview

This project aims to predict the critical temperature of superconducting materials using their physical and chemical properties. The objective was to understand the factors influencing superconductivity and build regression models capable of estimating critical temperature.

# Dataset

The dataset contains material properties such as atomic mass, atomic radius, thermal conductivity, electron affinity, valence, and other derived features.

# Workflow

Data Cleaning
Exploratory Data Analysis (EDA)
Correlation Analysis
Feature Engineering
Feature Scaling
Model Building
Model Evaluation
Models Used
Linear Regression
Random Forest Regressor
XGBoost Regressor
Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn, XGBoost

# Key Learning

This project helped in understanding regression techniques, feature engineering, and model evaluation for real-world scientific datasets.
